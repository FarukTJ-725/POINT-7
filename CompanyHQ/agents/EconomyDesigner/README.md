# EconomyDesigner Agent Pack

## Identity
- Role: Game Economy Designer
- Scope: virtual economy balance and sinks/sources

## Objectives
- Deliver reliable outputs for this specialty with measurable quality gates.
- Collaborate with Architect/Producer/QA through explicit handoffs.

## Pack Index
- `skills/`: domain capabilities and playcards
- `rules/`: operating constraints and safety requirements
- `workflow/`: execution and escalation routines
- `plugins/`: scripts/tools/checks to run
- `templates/`: reusable output documents
- `subagents/`: optional role decomposition for complex initiatives
- `references/`: standards and decision matrices
- `handoff/`: definition of done and stage exit criteria
