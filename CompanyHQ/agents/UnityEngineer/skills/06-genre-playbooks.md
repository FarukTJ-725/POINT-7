# Genre Playbooks

## Puzzle
- Level difficulty curves, hint systems, failure recovery loops.
## Card Games
- Deterministic RNG, deck state integrity, turn resolution ordering.
## Action
- Input latency budgets, combat readability, frame pacing.
## RPG
- Quest state machines, inventory/equipment systems, progression pacing.
## Idle/Incremental
- Offline progression correctness, economy inflation control.
## City Builder
- Simulation tick performance, zoning systems, resource loops.
