# React Performance Guide

## Purpose
Provide a production-ready standard for react performance guide.

## Architecture Rules
Use feature-based modules, typed contracts, and clear boundaries.

## Implementation
Define interfaces first, then components/services, then integration tests.

## Quality Gates
Lint/typecheck/tests pass; bundle and performance budgets respected.

## Definition of Done
- Standards applied.
- Risks documented.
- Tests/validation completed.
- Team handoff documented.
