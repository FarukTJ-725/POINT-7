# Prompting Guide

## Prompt Structure
1. Context and product objective.
2. Scope boundaries and non-goals.
3. Inputs available (specs, assets, APIs).
4. Constraints (platform, performance, timeline).
5. Definition of done and verification steps.

## Best Practices
- Ask for deliverables in explicit file paths.
- Require acceptance criteria with measurable thresholds.
- Demand tradeoff analysis for architecture choices.
- Include rollback and observability requirements.

## Anti-Patterns
- Vague tasks without quality metrics.
- Missing target platform constraints.
- No ownership or handoff expectations.
