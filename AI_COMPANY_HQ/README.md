# AI Company HQ

AI Company HQ is a production-grade operating system for a hybrid Game Studio + Web App Studio. It defines company governance, delivery standards, department ownership, agent responsibilities, reusable libraries, and execution workflows.

## Folder Map
- `/org`: governance, reporting lines, and decision logs.
- `/departments`: department handbooks and role/agent definitions.
- `/playbooks`: implementation guides for Unity, React, Backend, DevOps, QA, Product, Design, and Art/Audio.
- `/templates`: execution-ready planning, engineering, and QA templates.
- `/libraries`: reusable module standards and implementation contracts.
- `/workflows`: end-to-end delivery workflows from intake to liveops.
- `/scripts`: command standards and automation policy.

## Delivery Principles
1. Ship value every sprint.
2. Measure performance and quality in production.
3. Design for maintainability, modularity, and observability.
4. Keep security and compliance mandatory.
5. Align game and web engineering discipline to one professional quality bar.
