# Tool Routing

## Primary Tools
- Unity Editor + Profiler: gameplay and rendering systems.
- React + TypeScript + Vite/Next: frontend architecture.
- Node/Nest/Go/.NET: backend services.
- Docker + Kubernetes + Terraform: infrastructure.
- GitHub/GitLab CI: automation and governance.
- Datadog/Grafana/Prometheus: observability.
- Jira/Linear + Notion/Confluence: planning and decision records.

## Routing Rules
1. Route game runtime issues to Unity engineering first.
2. Route API contract issues to backend/API engineers.
3. Route deployment and runtime incidents to DevOps/SRE.
4. Route usability defects to UX + product.
5. Route release risks to QA Lead + Release Manager.
